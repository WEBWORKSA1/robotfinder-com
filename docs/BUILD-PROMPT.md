# RobotFinder.com — Business Idea & Phase-wise Build Prompt

## 1. The winning idea

**RobotFinder.com = "The search engine for robots": a robot directory, comparison site and multi-vendor quote marketplace.**

The name tells visitors what the site does, and it matches how people search ("find a robot for X", "best robot vacuum", "humanoid robot price"). The business idea follows from that.

### Why this model wins (numbers and logic)

| Revenue stream | Why it works for this domain | Typical economics (industry benchmarks) |
|---|---|---|
| **Pay-per-lead RFQ** (main earner) | B2B robot deals are $25k–$500k+. Vendors pay a lot for qualified buyers. | $50–$300+ per qualified B2B lead; exclusive leads earn more |
| **Affiliate** (vacuums, mowers, drones, STEM kits, robot dogs) | Consumer robots cost $150–$3,000, so each commission is large | ~3–4% on Amazon; brand programs pay 5–10% |
| **Google AdSense** | Tech and B2B-industrial pages pay well above average | Tech / industrial RPMs are above general-content averages |
| **Featured listings & category sponsors** | Robotics is crowded (humanoids, cobots, AMRs), and makers need visibility | $199–$599/mo per vendor |
| **Newsletter / video sponsorship** | A weekly "Robot Brief" builds an audience the site owns | $25–$60 CPM for a B2B newsletter |
| **Jobs board, events, contests, awards** | These pages attract search traffic and repeat visits | $99–$249 per job post; sponsor-funded prize pools |
| **Donations** | Reader support for an independent site | Small, but it builds community |

**Competitive gap (from the 29-site review):**

- humanoid.guide, aparobot and robozaps cover only humanoids and cobots.
- RobotShop is a store, not a neutral guide.
- The Robot Report and Robotics 24/7 are news sites with no buyer tools.
- **No site combines** all robot categories with comparison, ROI, multi-vendor RFQ, consumer affiliate links, video, jobs and contests. RobotFinder fills that gap.

**The bolder option:** turn the database into a data business. Sell paid "Robot Sourcing Briefs" ($1,950–$9,500, the robozaps model), market reports, and a "RobotFinder 50" annual award with nomination fees and badge licensing.

## 2. Phase-wise build prompt (copy each phase to an AI builder or developer)

> **Global rules (apply to every phase)**
> - Domain: RobotFinder.com. Static HTML/CSS/vanilla JS, hosted on the free GitHub Pages plan (no server).
> - Every page begins with a top bar reading **"Contact, if you are interested in this website/domain name"**, linked to `https://web.works/contact`.
> - All forms and contact links deliver to one private inbox. **That address must never appear in HTML, text or links.** Keep it obfuscated in JS and send through a form-to-email API (FormSubmit AJAX, later swapped for its alias hash).
> - Mobile-first, responsive, accessible (WCAG AA), dark/light theme, Core Web Vitals under 2.5 s LCP.
> - Every page has SEO title, description, canonical URL, Open Graph tags and JSON-LD schema.

### Phase 1 — Foundation & design system
Prompt: *"Create a static site skeleton for RobotFinder.com:*
- *one data file plus a renderer that builds the shared header, footer and every page template; light SEO stub pages generated by a small Node script;*
- *a design system with CSS variables for light and dark themes, Inter / Space Grotesk fonts, cards, buttons, chips, badges, grids and forms;*
- *a sticky header with a mobile menu, a domain-inquiry top bar, a mega footer with newsletter signup, a favicon, robots.txt, sitemap.xml, ads.txt and .nojekyll."*

### Phase 2 — Robot database & directory
Prompt: *"Build a robot data model (slug, name, maker, category, year, price or quote, status, country, buyer type, YouTube id, maker URL, affiliate query, summary, specs map) with 16 categories:*
- *humanoids, quadrupeds, cobots, industrial arms, warehouse/AMR, home cleaning, lawn/garden, companion, education, research, drones, medical, service/delivery, security, agriculture, underwater.*

*Generate:*
- *a directory page with instant search (natural-language 'under $20k' parsing), filters (buyer type, availability, max price, category) and sorting (featured / newest / price / A–Z);*
- *one SEO page per robot, with spec table, lite-YouTube embed, sticky quote form, affiliate 'check price' link, official link, similar robots and Product schema;*
- *one page per category."*

### Phase 3 — Lead generation engine (highest priority)
Prompt: *"Build `/get-quotes.html`, a 7-step RFQ wizard with a progress bar, auto-advancing option tiles, per-step validation and hidden lead scoring (budget + timeline + role + phone → HOT / WARM / NURTURE). The steps are:*
1. *Buyer type*
2. *Category + application*
3. *Scale (units, sites, payload, shifts)*
4. *Budget, including RaaS*
5. *Timeline + decision role*
6. *Organisation (industry, size, country)*
7. *Contact details + consent to share with up to 3 vendors*

*Also add:*
- *a trust panel, a how-it-works box and an FAQ with schema;*
- *secondary lead capture everywhere: robot-page quote forms, ROI report form, exit-intent lead magnet ('2026 Robot Buyer's Checklist'), newsletter, sourcing-call request, and CTA bands on every template."*

### Phase 4 — Buyer tools
Prompt: *"Build:*
- *a Compare tool: up to 4 robots, a union of spec rows, a sharable `?ids=` URL, a floating compare tray and 'popular comparisons' chips;*
- *a Robot ROI Calculator: hardware, integration, maintenance, wage, operators, shifts, hours, days and gain %, giving payback, annual savings, 3-year ROI and 5-year net, with a 'vendor-validated ROI report' lead form;*
- *a Robot Matchmaker widget on the homepage."*

### Phase 5 — Content, video & SEO engine
Prompt: *"Build:*
- *a guides hub with long-form articles (price guide, cobot vs industrial, humanoid buyer's guide, robot vacuum guide, ROI guide, RaaS explained), each with Article schema, in-article and sidebar ad slots, a newsletter box and a quote CTA;*
- *a Video Hub of curated YouTube videos with category filters, a subscribe CTA, a video-submission form and VideoObject schema.*

*Plan programmatic SEO next: 'X vs Y' comparison pages, 'best {category} {year}' lists and 'robots for {industry}' pages."*

### Phase 6 — Monetization
Prompt: *"Build a single `config.js` with:*
- *AdSense client and slot ids (auto-inject the loader and `<ins>` tags into every `.ad-slot`; show placeholders until approval);*
- *GA4 id;*
- *Amazon Associates tag (rewrite `data-amz` links with rel="sponsored");*
- *donation links (PayPal, Stripe, BMC, Ko-fi, GitHub Sponsors).*

*Build `/advertise.html` with Featured Listing, Category Sponsor, Newsletter, Video Review, the pay-per-lead program, contest sponsorship and a media-kit request form. Build `/list-your-robot.html` for vendor submissions and profile claims. Add affiliate disclosure, privacy (AdSense cookie language, GDPR/CCPA/PIPEDA) and terms pages."*

### Phase 7 — Community: donations, hiring, contests, events
Prompt: *"Build:*
- *`/donate.html`: fund allocation (operations, promotions/marketing, hiring talent, contests & prizes), monthly tiers, an amount picker, frequency, fund selector, supporters-wall opt-in and payment-link buttons from config;*
- *`/jobs.html`: RobotFinder's own open roles, a talent-network application, employer job posting ($99 / $249) and external job-board links;*
- *`/contests.html`: Video Challenge, Student Build Challenge, Robot Idea Prize and Photo of the Month, with a live countdown, one entry form, sponsor/donate CTAs, official rules and major external competitions;*
- *`/events.html`: a global robotics events calendar plus a paid or free event-submission form."*

### Phase 8 — QA, performance, deploy
Prompt: *"Run a headless-browser smoke test on every page. Check for:*
- *console errors;*
- *horizontal scroll at 390 px;*
- *correct results from filters, compare, ROI and wizard.*

*Confirm the private email string appears nowhere in the built files. Push to GitHub repo `WEBWORKSA1/RobotFinder-com` and publish with GitHub Pages from the `main` branch root. Later, add `CNAME` = robotfinder.com and DNS records (A 185.199.108–111.153, CNAME www → webworksa1.github.io)."*

### Phase 9 — Scale (post-launch roadmap)
- Grow to 500+ robots: an admin CSV → data-file pipeline, and a vendor self-serve portal (Supabase/Firebase when outgrowing static hosting).
- Pre-render pages to full static HTML at build time for maximum SEO once the catalog grows.
- Programmatic "vs" pages, a "Best of" list for each category, and industry landing pages (warehousing, restaurants, hospitals, schools, farms).
- "RobotFinder 50" annual awards with nominations, a winners' page and badge licensing.
- Weekly "Robot Brief" newsletter (Beehiiv / ConvertKit) with a sponsor slot.
- YouTube channel: Robot of the Week, reviews and Shorts, embedded back on the robot pages.
- Paid Robot Sourcing Brief ($1,950) and market reports.
- User reviews, ratings, want/own lists and Q&A.
- Localisation (FR/ES/DE/JA/ZH) and multi-currency pricing.
